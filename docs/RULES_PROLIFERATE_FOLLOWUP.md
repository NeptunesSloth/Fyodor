# Following actual proliferate counter puts

Ripples of Potential’s proliferate action records positive counter-put events, then offers
only its controller’s permanents whose current object IDs received counters in that action
(CR 701.34). A counter prohibition does not qualify. The choice is untargeted and supports
noncreatures and any counter kind. Chosen permanents use normal phasing (702.26), keeping
identity and counters and returning at the controller’s next untap step.

A separate instruction opens the receipt scope before proliferate. The ordinary counter
replacement continuation records actual events after all ordering choices. When Tekuthal
repeats proliferate, its nested resolution contexts propagate their receipts back to the
original effect. This tracks puts rather than inferring them from final counter totals.
