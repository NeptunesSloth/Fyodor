# Resolving source-quality protection

The native source-quality foundation supports Crypsis, Devoted Caretaker, Floating Shield, Dominaria's Judgment, and Lord of the Nazgûl using their canonical Oracle text.

Crypsis grants a dynamic compound creature-and-opponent-controller quality. Its official ruling specifies that subsequent control changes of the protected creature redefine 'your opponents' relative to its new controller. The protected recipient's current controller is supplied when evaluating its protection qualities. Opponent-owned creature cards outside the battlefield qualify through the existing owner fallback, also as explicitly ruled. Devoted Caretaker binds the Instant/Sorcery card type together with actual spell status: an activated ability from a card with those types is not itself an instant or sorcery spell. Non-target damage from actual spells receives the same source flags used for targeting, without changing underlying characteristics.

Floating Shield's native activated grant reads its own entering-color choice. A saved ObjectSnapshot now carries public choices (default empty for old saves), captured before sacrifice or another zone change. Resolution uses the original source object ID; a returned physical card with a fresh color cannot overwrite the pending ability's original Red choice. A resolving color choice still uses its existing path, and definitions without exactly one native entering color choice remain refused. The Aura's existing “This effect doesn't remove this Aura” exception remains intact.

Dominaria's Judgment evaluates controlled lands' current subtypes at resolution, collects all qualifying basic land colors once, and grants those protections to the current creatures as one ordinary layer-six effect. Dual lands and Dryad's subtype changes count. Later changes to lands or creature population do not change the locked grant.

Lord of the Nazgûl uses a source Ring-bearer designation, not legendary status or a copiable ability. Current derived source characteristics receive a boolean from the native controller-to-object-ID designation map. ObjectSnapshot captures the boolean before action handlers move the source or designation reconciliation clears it. Exact last-known source reconstruction restores it, allowing a dead Ring-bearer's Goblin Arsonist trigger to have its damage prevented. A Clone does not copy the designation, and control changes remove live Ring-bearer status.

The quality predicates are shared by damage prevention, target legality, attachment legality and blocking restrictions (CR702.16). All new persistent snapshot fields have backward-compatible empty/false defaults. No callback or UI protocol changes are introduced.

Canonical data and gameplay tests are in tests/fixtures/source_quality_grant_cards.json and tests/test_rules_source_quality_grants.py. They exercise native costs, sacrifice/LKI, reincarnation, multiple opponents, real spell-versus-ability targeting, real non-target spell damage, dual/basic land subtypes, Ring designation changes, cloning, replay/save-load and fresh-process continuation of a paid Shield ability.

Targeting carries a distinct ephemeral targeting_controller for the controller of the spell or ability. Player-specific protection reads this field (CR702.16k); compound creature-controller qualities read the actual source object_controller. A native Orcish Bowmasters source stolen after its trigger targets a Crypsis-protected creature consequently has its sole target become illegal and does not amass. Source damage and source LKI retain the actual controller.
