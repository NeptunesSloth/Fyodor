# Spreading Plague — held for shared-kernel review

Spreading Plague is **not admitted**, and its live definition and primitive hooks were removed. Its exact leaf reads the entering object's current characteristics or native last-known information once, then delegates one ordinary native destruction batch using a Creature/color union selector excluding only the exact original event ObjectRef. A blinked successor is therefore another creature. The native no_regen marker disables regeneration while retaining other destruction replacements.

The native initial16 checks and18 existing radiance/regeneration checks passed in production before hooks were removed. Two extra ordinary/multi-Umbra replacement-choice proofs exposed a preexisting shared destruction bug: an ordinary creature with two applicable Umbra Armor Auras receives no owner decision. The same failure was independently reproduced using the already supported, actually paid Wrath of God without Spreading Plague. `regeneration_choices.prepare` only prepared automatic-regeneration or regeneration-rider objects, bypassing multiple ordinary replacements.

The [proposed shared fix](proposals/trigger61-multiple-destruction-replacement.patch) preserves both existing paths and includes ordinary objects with more than one applicable replacement option. All options, APNAP affected-controller decisions, serialized original ObjectRefs, replay, protection, and finishing remain native. This proposal is **not installed**; root review is required. The [native Wrath reproduction](proposals/trigger61-native-destruction-frontier.py) and [subsequent leaf hooks](proposals/trigger61-plague-hooks.patch) are durable review artifacts.
