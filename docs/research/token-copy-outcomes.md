## Implementation details and native boundaries

Battle for Bretagard opts into native nontarget `distinct_names` validation. Under CR 201.2b every selected object must have a name and no two selected objects may share any name; unlocked Room multi-names use the existing `card_names.names_of` representation. Ordinary non-target choices are unchanged.

Nahiri's duration uses the existing `until` wrapper, which captures the original effect controller and creation turn and expires at that player's next turn. Passing a duration string directly to `restrict` would omit those native duration receipts.

Native token-copy requests retain a complete copy recipe and the full computed characteristics for replacement queries. For Changeling, the bounded token transport type-line field omits the computed hundreds-of-subtypes expansion; the authoritative recipe restores all creature types before entry effects and state-based actions. Altaïr's actual Changeling Outcast copy covers this preexisting transport defect.

All newly parsed bindings use ordinary `as` and `ref:` metadata so spell-clause renaming, saved choices, and private object renumbering remain native. Library copy authorization applies only to exact currently public revealed refs explicitly supplied by the printed effect. It grants no general hidden-zone permission.
