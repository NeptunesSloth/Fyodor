# Armored Skyhunter: private look and optional Equipment attachment

The exact attack-trigger body delegates to a leaf sequence: privately look at up to six actual library objects; optionally choose one Aura or Equipment card; enter it through native attachment/replacement handling; optionally attach an Equipment that actually entered to a legal creature you control; randomize the remaining original library objects onto the bottom in one native move.

Aura entry is mandatory attachment to a legal host without targeting (303.4f–g). An opponent's hexproof creature is a legal host when its enchant restriction allows it. With no legal host the Aura stays in the library and belongs to the random rest. Equipment enters first, then offers an optional attachment to any creature controlled by the ability's controller, not only Skyhunter. The attachment can be declined. Actual post-entry characteristics and native host legality apply: an Equipment animated by March of the Machines cannot equip without reconfigure. Equipment controller and equipped-creature controller need not be the same (301.5d).

The original selected library object is correlated with its actual native zone-change event to establish that this effect put the current Equipment onto the battlefield. Entry prohibitions leave it among the remaining original library objects. Entry redirections out of the library do not send the old object back. Rest cleanup uses exact ObjectRefs, so unrelated replacement objects are not accidentally bottomed. Source departure does not end the trigger's instructions.

Look selection is private; native Aura-entry choices and the entering permanent use normal public visibility. Cleanup closes the view once and calls native bottom_at_random, whose recorded shuffle/move preserves replay while hiding randomized positions. Empty libraries do not create a view or attempt to close a nonexistent one. Eager module registration includes both custom choice callbacks. Tests execute saved pick and attachment decisions in fresh Python processes without importing this leaf first, then verify history reconstruction.

Canonical fixtures contain full current Oracle metadata. Tests cover both Equipment outcomes, another controlled host, opponent hexproof Aura attachment, no Aura host, creature Equipment blocked by Grafdigger's Cage, Equipment animation, source departure, private choice, random rest, empty/no-eligible libraries, JSON continuation, and cold continuation.
