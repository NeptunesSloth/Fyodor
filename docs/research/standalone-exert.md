# Standalone exert and observers of the exert action

Five canonical Oracle cards use a standalone optional attack-exert sentence and a separate exert observer: Rohirrim Chargers, Battlefield Scavenger, Trueheart Twins, Resolute Survivors, and Vizier of the True. The exact standalone sentence is classified as a static attack-exert marker. The native attacker-choice scan accepts that marker alongside existing linked `When you do` exert triggers. Existing Combat Celebrant once-per-turn gating and linked reflexive dispatch remain in place.

One native helper performs both attacking exert and activated/mana EXERT costs. It preserves existing next-untap and last-exerted-turn bookkeeping, then emits an individual exert event with the exact object, exerting player, and card types at that moment. A generic observer filters the actual actor and the creature qualification. Old event shapes remain readable with an optional type snapshot and fallback. Exert does not itself tap a permanent. Repeated exert creates separate action events while retaining one pending next-untap restriction; a cancelled activation proposal emits no paid action, and countering an activated ability does not undo an already paid exert.

The four ordinary observer bodies reuse native discard/payment/draw, team pump, multiplayer damage/life, and targeted tap logic. Rohirrim uses a bounded leaf: publicly reveal through the first Equipment, enter the card through native attachment handling attached to the exact exerted object when possible, then random-bottom the remaining original library objects. A departed or replaced creature is never substituted as the host. Source departure does not remove the existing trigger. Reveals use native card-ID chunks instead of the capped RevealTop action, supporting libraries larger than 100 cards. No Equipment means randomizing the revealed library without drawing or losing the game.

Tests cover all five exact Oracle definitions, optional exert, two simultaneous exerted creatures, linked-trigger nonduplication, other-creature observers, native mana exert, actor exclusion, private optional discard, repeated exert and one actual next untap, an extra combat, vigilance, source/host departures and replacement objects, no Equipment, libraries over 100, additional-cost cancellation and a real Stifle. Saved choices execute in fresh Python processes without warming the new leaf and rebuild identical history. Related native exert, activated costs, Combat Celebrant, and additional-upkeep regressions remain green.

Rules basis: CR 701.43a–d, 508.1g/m, 603.12/607.2h, 400.7, 101.4/603.3b, 301.5c/d and 701.3. Existing untap bookkeeping is reused; no new untap implementation or casting-permission flow was added.
