# Tokens with every basic land type

[Overlord of the Hauntwoods's official rulings](https://api.scryfall.com/cards/05d08ff1-edcc-4c76-96e0-683b3da36ebb/rulings) state that its Everywhere token has the subtypes Plains, Island, Swamp, Mountain, and Forest, and the intrinsic mana ability of each type. It does **not** have the basic supertype.

The creation instruction defines those five subtypes as part of the token's initial, copiable characteristics (CR 111.3, 205.3i). It does not give the token a characteristic-defining ability or an ability to produce five mana simultaneously. Rule 305.6 gives five separate tap abilities, each producing one mana of its type.

The token enters tapped and colorless. The normal token-replacement pipeline applies, including Doubling Season. Its five land subtypes satisfy all five domain types even if its controller controls no other lands. Because it is nonbasic, Blood Moon replaces its land subtypes and intrinsic mana abilities with Mountain and its red mana ability (CR 305.7).

The generic grammar can accept a quantity, tapped status, and explicit token name with this description; no card-name-specific behavior or new runtime action is needed.
