# Variable life instructions and original object receipts

The nine-card batch41 leaf automates Sheoldred's Restoration, Essence Vortex, Kaya, Orzhov Usurper, Niv-Mizzet, Guildpact, Elixir, Shadowgrange Archfiend, Orzhov Charm, Shriveling Rot and Pact Weapon. Full canonical rows and official rulings are saved under `/tmp/fyodor-life41-{canonical,rulings}.json`; the all-printed-line plan is `/tmp/fyodor-life41-plan.md`. Black Panther remains gated on a separately researched counter-movement receipt meaning.

Variable values are frozen at the actual instruction. Kaya's damage and gain use the same nominal exile-card count even when damage is doubled; Niv's three instructions use one distinct two-color-pair count. Orzhov Charm loses the original toughness even when destruction fails and returns only Auras controlled by its caster. Sheoldred reads the actual kicked spell receipt and uses native reanimation and resolving-spell self-exile. Illegal targets use normal fizzle handling.

Essence Vortex offers an actual native life payment to the target's current controller and prohibits regeneration only for its destruction. Elixir's native shuffle instruction now optionally records the number of actual moves into the library before shuffling. Hidden-zone object references stay hidden; the following gain consumes only a numeric receipt. Countered or copied activations retain normal native cost semantics.

Pact Weapon's attached restriction protects the Equipment controller from the zero-life state-based action only. Its attack trigger captures the original attacking creature, independently of later Equipment attachment or departure. Original-draw history and existing replacement ancestry distinguish an original draw from a replaced draw, including replacement effects that draw more cards. Only the actual original result is revealed and used for the bonus/loss; a replaced draw produces neither. No new broad last-drawn-card shortcut is used.

Shadowgrange's entry instruction uses actual native greatest-power sacrifice choices and original sacrificed-object powers. The gain is their maximum, not sum. Mixed Madness alternatives use ordinary alternative-cost parsing and a single total-cost payment: the mana and fixed life component are composed with additional costs before native choice/payment. Impossible nonmana payments are excluded from the offer, and decline uses the ordinary Madness graveyard transition. Existing pure-mana Madness continues through the same native path.

Shriveling Rot uses two separate normal, counterable, turn-long triggered watches. Damage does not create a new incarnation, so its deferred destruction binds the actual damaged object; death uses ordinary last-known toughness/controller. Native mode and entwine payment determine which watches exist. No immediate-destruction shortcut or inferred death is introduced.

Native evidence is in `/tmp/fyodor-life41-final-focused.log`, the separate flying/hexproof and foreign-Aura cases, and `/tmp/fyodor-life41-related.log`. Four genuine pending fresh-process continuation classes cover Vortex payment, Madness total payment, Pact's optional draw replacement, and Elixir's ordered life replacement; saved history/replay checks accompany them. These admissions remain subject to the central batch41 catalog and integration audit.
