# External mana payment consumers

Assist helper payments, Licid effect-ending special actions, and Room unlock special actions now register typed, serializable post-payment stages with payment_continuations. Each automatic payment calls casting.pay_then and returns immediately. The payment API invokes the terminal once for both synchronous payment and resumed replacement choices; callers do not repeat the original intent or pay costs again.

Licid terminals retain the identities of the continuous effects to end. Room terminals retain the permanent's original object identity and the selected door. Assist terminals add the helper's payment note and dispatch the caster's existing post-helper continuation. Self-payment Room actions retain their pool-only behavior and share the same designation terminal.

The integration fixture uses actual Oracle Calming Licid, Grand Entryway, Huddle Up, and Abundance. Payment Test Spring is explicitly synthetic and has legal printed text “{T}: Add {W}.” An explicitly requested fixture injects a structured draw rider below Oracle classification to isolate the continuation boundary. Under pinned CR 605.1a, an ability that moves a card to or from a library is not a mana ability, so no printed draw-bearing ability is claimed to qualify. Canonical Chromatic Sphere and the Egg artifacts are ordinary activated abilities under CR 605.1a and use the stack; they are not automatic payment sources. Each action is exercised synchronously, with Abundance declined, and with Abundance accepted through its second private land/nonland choice. Every paused decision and final state is checked through save/load and replay.
