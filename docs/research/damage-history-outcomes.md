# Damage from turn history and exact instruction receipts

Twenty exact printed sequences use native queued damage, movement, draw, optional-cost and target instructions. Values read the specified current object or exact original-object last known information. Every simultaneous instruction becomes one native damage batch.

Whipkeeper reads actual damage facts rather than removable damage marks. Sentinel Tower binds the triggering cast's position in public cast history. Builder's Bane counts actual graveyard deaths per former controller; Tuktuk's conditional follow-up rejects regeneration, indestructibility, replacement exile and declined destruction. Dead Reckoning captures graveyard power before moving the card. Friendly Fire uses the native random reveal receipt. Malignant Growth counts the affected player's actual additional draws, excluding the normal draw-step card.

Unnatural Hunger uses native optional sacrifice payment with an exact bound original-host exclusion. The small optional-payment extension reads only matching current context objects, preserves the actual effect controller and payer, restores temporary exclusions after validation, and defaults to existing behavior. Real source destruction, host blink into a new eligible incarnation, opponent sacrifice protection and cold cost choices are covered.
