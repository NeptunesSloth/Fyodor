# Activated card outcomes

Batch37 adds native compositions for Reckoner Bankbuster, Fire Nation Turret, Dwarven Armorer, Mondo Gecko, Krumar Initiate, Cloudseeder, Sparkspitter, Soldevi Sage, Mercadian Lift, Deepwood Elder, Flowstone Sculpture, Possessed Goat, and Trade Caravan. Canonical records, exact probes and official WotC rulings are in `/tmp/fyodor-activated-outcomes37-*`.

The leaf queues ordinary native effect descriptors. Counter/keyword alternatives are choices during resolution, not activation modes. Mondo chooses one color, replaces its colors, and grants the corresponding independent hexproof ability until end of turn. The two named creature tokens use native self-creature rules text so their blocking, crewing and end-step abilities run normally; they have no printed mana cost. Bankbuster creates both token kinds in one native creation batch. Soldevi Sage records actual original draws, permits only those exact still-present hand objects for its private discard, and excludes replacement-generated cards under CR121.6c. Mercadian Lift reads announced X rather than remaining counters. Deepwood Elder uses exact X target groups and the existing Forest-setting layer effect.

Native cost grammar now reads fifty source counters and Pay X life. Announced X sizes the latter before affordability checks, reserves that life during mana payment, and uses the existing scalar life payment exactly once. Trade Caravan's restriction uses the native opponent-upkeep predicate. Possessed Goat preserves its existing once-per-object lifetime restriction and adds its color/type through native effects.

A genuine existing Endure error was demonstrated with actual Krumar activation and Solemnity: the resolver offered a forbidden counter payment. The corrected native Endure path creates the Spirit when counters cannot be put on the permanent (CR701.63a,608.2d), matching the official ruling. `/tmp/fyodor-endure37-before.log` fails before correction and `-after.log` passes. Existing Fortress Kin-Guard Endure regressions run separately.

Verification includes all13 canonical activated outcomes, every resolution-choice branch, five fresh-process resumes, private actual-draw subsets, paid-X life and zero/insufficient costs, physical counter removal, creature-land Forest retention, token mana value, Pilot native crew, and actual Spark Elemental end-step sacrifice. Final counts and broader regression results are recorded in CURRENT_STATE as they complete.
