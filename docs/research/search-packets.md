# Qualified search packets and subsequent choices

Canonical family: Burning-Rune Demon, Threats Undetected, Ecological Appreciation, Signal the Clans and Emergent Ultimatum. Canonical fixtures include all printed characteristics and support cards. Reuses the existing Gifts/Intuition search and opponent-choice pipeline in refused_zones.py, with a declarative search_packets parser. No casting or mana implementation changes.

CR 701.23b permits failure to find cards with stated qualities in hidden zones. Search constraints include distinct names using card_names.share (front-face names for double-faced cards and shared-name semantics, CR201.2a), fixed name exclusion, and numerically distinct powers. Threats uses current derived power, including characteristic-defining abilities in the library; the tests compare a real 2/3 Tarmogoyf against Grizzly Bears to reject equal power despite different names/toughness.

Burning-Rune Demon uses native optional trigger resolution before searching: declining does not shuffle. Once accepted, its qualified search can find fewer cards; the literal excluded name remains Burning-Rune Demon, independent of source identity. Source text's normalized self reference is not used to infer a changing runtime card name.

Ecological Appreciation accepts library and graveyard objects, respecting library-only search limits/prohibitions. Opponent choices put at most two found cards into the library; the remainder enter under the original caster's control. Ordinary native entry replacements, including Clone choices, retain that controller across cold resume. The spell exiles itself after its instructions finish. The WotC 2021-04-16 ruling explicitly says one or two found cards produce no battlefield creatures, while finding three still shuffles two.

Signal the Clans deliberately does NOT impose different names at search time. Only three revealed cards with distinct names produce one random card in hand; otherwise all found cards remain in the library and it simply shuffles. This follows WotC 2013-01-24 rulings. Native resolved moves and shuffle randomness replay deterministically; no random decision is recomputed from saved state.

Emergent Ultimatum physically exiles the found monocolored cards before the opponent chooses one to shuffle back. Colorless cards are excluded. Remaining exact exile objects are offered through the existing optional free-cast continuation, during the original spell's resolution. The original stays on the stack throughout that window, then exiles itself. Ordinary native restrictions, mandatory additional costs, X=0, targets and multiple cast order apply. An actual Counterspell can initially target Emergent but loses its legal target when the original exiles before that Counterspell resolves; this is also stated in the WotC 2025-04-04 ruling. A card leaving exile and returning is not the permitted object.

Opposition Agent still controls the native search and diverts library finds to exile with the Agent's permissions rather than allowing the ordinary packet split. Mixed-zone packets leave graveyard finds on their normal path. Aven Mindcensor limits only the library portion; a prohibited library search does not erase legal Ecological graveyard choices. Each completion uses one native shuffle and actual shuffle-trigger machinery.

Tests cover canonical FULL checks and actual gameplay for zero-to-four found cards, name/power validation, optional decline, actual graveyard sources, search replacements, original-controller entry choices, exact exile refs, multiple free casts, X=0, unpaid mandatory additional costs, resolving-spell targets and source exile. JSON cold restoration and history replay run at each native decision. REST/WebSocket integration verifies private search options, public revealed packets and hidden hand destinations separately.

Official ruling evidence was retrieved via Scryfall's WotC-sourced ruling endpoints for all five cards. These rulings, and the local Comprehensive Rules snapshot dated 2026-09-25, guide the bounded typed extensions. Turtles Forever remains outside this family because its outside-game collection requirement needs a separate collection-aware extension.
