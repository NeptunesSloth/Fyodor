# Hit the Mother Lode: discover followed by an instruction

The [official rulings](https://api.scryfall.com/cards/e75f460c-43e2-4353-8b73-71ff8651a79d/rulings) explicitly require the player to finish discovering before creating Treasures. A discovered Shrapnel Blast cannot sacrifice one of these future Treasures to pay its mandatory additional cost. If it cannot be cast, it is put into the player's hand, and the following Treasure creation still happens.

CR 701.57a describes the exile/cast-or-hand/bottom process. Under 701.57c the last eligible card is the discovered card whether cast or put into hand. If no eligible card is exiled, there is no discovered card and no Treasures are made. Mana value 10 produces a difference of zero.

The card's last public mana value is captured while it is exiled. CR 400.7h permits following parts of an effect that allows casting a card to find the new stack object, and CR 608.2h uses current information of that public object. Thus casting Galvanic Giant (mana value 4) produces six Treasures; casting its Storm Reading Adventure (mana value 7) produces three; putting the card into a hidden hand uses the last public card information (4) and produces six. Likewise Fire // Ice has combined mana value 4 in exile/hand and a cast Ice spell has mana value 2: the respective differences are six and eight. The official ruling list explains that discover can cast different halves/faces but does not explicitly restate the later-information calculation; that calculation follows the cited comprehensive rules.

The implementation adds an opt-in continuation for typed discover follow-ups. Ordinary discover/cascade/suspend behavior is unchanged. `discover` binds the card and its public mana value, then marks the cast offer to retain the original resolution. The existing granted-cast continuation handles success and abandonment; declining also resumes the original effect. A following typed measure computes the difference, and the existing `create_token` primitive creates tapped Treasures through its normal replacement pipeline. The source spell remains on the stack until the discovered spell is legally cast, declined, or abandoned and the Treasure instruction completes. This also permits save/load during target/cost choices and token replacement ordering.

Verification: 17 focused gameplay tests cover cast/hand, no hit, skipping mana value 11, mana value exactly 10, Drannith Magistrate prohibition, Adventure and split-card information, mandatory additional-cost impossibility, cancelling a cast before paying the cost, doubled Treasures, and an interrupted Doubling Season/Peregrin Took token replacement order. All choices are checked for replay and JSON save/load. The 51 existing granted-face, ripple/free-cast, and optional-cost regressions pass. Fixtures include complete canonical colors, identity, mana value, keyword, power/toughness, layout, and face metadata from the local Oracle database.
