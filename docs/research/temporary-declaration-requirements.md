# Temporary declaration requirements

Twelve canonical cards are covered: Provoke, Predatory Rampage, Academic Dispute, Timely Interference, Monstrous Step, Chemister's Trick, Incite, Auriok Siege Sled, Feral Contest, Kookus, Domineering Will and Aggravate. Fixtures preserve actual Oracle colors, mana value, keywords, types and other relevant metadata. One explicitly synthetic modal composition harness tests target-group offsets; it is not an additional claimed card.

The shared parser leaf `declaration_requirements.py` feeds existing `must_attack`, `must_block`, `must_block_obj` and `cant_block_obj` rules. Native combat legality and declaration-group optimization determine which requirements can be satisfied (CR 508.1d, 509.1c); no declaration solver or payment engine was added. Blocking wording now accepts exact antecedents, plural groups and typed artifact-creature targets rather than only the narrow phrase 'target creature'. Compound pump/color/damage instructions share the same object as their attack requirement. Paired spells preserve distinct target groups and the exact original creature another creature must block. Embedded target-group arguments are renumbered together with ordinary target fields when spell lines or modes are combined.

Rule-modifying group effects remain dynamic (CR 611.2c). Predatory Rampage's block requirement reaches later opposing creatures, while its characteristic-changing +3/+3 pump affects the original controlled group. Specific targets remain exact objects, so blinking the original first target neither pumps its new incarnation nor forces another creature to block that new object. Attack and block taxes remain optional; requirements never force paying a declaration cost. Impossible blocks, such as a ground creature against flying, are not required.

Academic Dispute's optional reach uses an existing native continuation that skips only that instruction when declined; Learn still resolves independently. Native Commander Learn offers optional discard/draw, respecting CR 903.11's restriction on importing outside-game cards. Timely Interference's kick condition and Chemister's Trick's overload reuse existing cost mechanisms. Domineering Will's chosen player gains control of the selected nonattacking creatures, untaps them, and must block if legal; native control duration restores the previous controller at cleanup.

Kookus validation exposed a separate normalization issue: self-name replacement must preserve literal names introduced by 'creature(s) named', just as it already preserved token and card names. Keeper of Kookus remains its complete literal name. The actual upkeep condition is checked both when triggering and on resolution; a Keeper entering in response prevents the damage and requirement.

Aggravate uses existing native damage-recipient capture after prevention and replacements. The restriction reads the same namespaced `dealt` binding as native exile/death replacement readers and locks only the exact damaged object IDs. Protected creatures, zero/prevented damage and later entrants do not acquire an attack requirement. No custom damage or replacement callback was introduced.

Forty-one focused cases cover actual positive effects for every canonical card, negative declarations, current colors and power/toughness, independent draw/optional effects, exact identity and distinctness, zero optional targets, control restoration, dynamic group membership, intervening conditions, prevention, tax exemptions, replay and a fresh-process restored paired spell. Related declaration, combat, modal and card-name suites supplement these proofs.
