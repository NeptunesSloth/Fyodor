# Thousand-Faced Shadow

The canonical Oracle ability triggers only when this creature enters directly from its controller's hand, with an intervening condition that it is attacking. Casting it from hand enters from the stack and does not satisfy the event. Ninjutsu supplies the normal direct hand-to-battlefield entry while attacking.

Two generic grammar normalizations supply existing native operations. A self-entry trigger's initial “if it's attacking” is bound to the source object before native intervening-condition parsing. A token-copy instruction followed by “The token enters tapped and attacking” is parsed as the same creation instruction with its entry modifiers. Neither normalization changes general object-state grammar or targets.

The native target selector requires another attacking creature, checks its continued legality on resolution, and does not impose an extra “you control” condition. Source attacking state is checked at trigger and resolution; if the source leaves, its original object's last-known state is used. The native copying engine preserves copiable values and applies token-creation replacements. Each resulting token independently chooses a defending opponent, planeswalker, or battle through the normal serialized entry-attacking decision. The chosen defender need not match either the copied creature or Thousand-Faced Shadow. These creatures enter attacking rather than being declared as attackers, so attack taxes do not apply.

Canonical gameplay tests use actual ninjutsu announcement, its returned-attacker cost, native entry target selection, and save/load/replay at choices. They cover Parallel Lives and different defenders for its two tokens, no other attacker, Reconnaissance removing source or target from combat, departed source last-known information versus a departed illegal target, actual normal casting, actual Elvish Piper hand entry without attacking, actual Reanimate graveyard entry, and entering through Ghostly Prison without paying its attack tax.

Validation: 12 canonical tests passed, plus 81 existing Silver-Fur Master/ninjutsu cases and three Kaalia, Kari Zev, and Phantom Steed entry-attacking regressions (96 unique tests). Ruff passed.
