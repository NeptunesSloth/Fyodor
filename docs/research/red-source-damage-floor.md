# Dynamic damage floors and colored-source history

Ojer Axonil, Deepest Might replaces noncombat damage below its current power from red sources its controller controls, only to opponent players. CR 120.8 means a zero-damage instruction cannot become positive damage. CR 616 requires rechecking applicability after another replacement changes the amount: with Shock, Ojer first then Torbran deals 6, while Torbran first yields 4 with Ojer no longer applicable. Furnace similarly yields 8 or 4. This requires a typed dynamic below-value match plus a dynamic set-value operation, rather than applying an unconditional maximum alongside other damage modifiers.

Existing replacement source snapshots already carry colors and controller, and existing value evaluation can read the replacement source's current power. Existing affected-player replacement ordering should remain in charge.

Temple of Power aggregates actual red-source noncombat damage across all recipients and sources its controller controlled at the time. Current turn facts retain source types and controller, but need a backward-default source_colors field on both player and permanent damage facts. Extend the existing source_damage history query with source-color and combat filters plus aggregate-total mode; preserve Dragon Cultist's default per-source threshold. Prevented damage, life loss and combat damage do not count. Source departure, control changes, or later color changes cannot rewrite past events.

Canonical transform-card fixture retains both real faces through importer card_faces. Tests cover current power, recipient exclusions, Torbran/Furnace ordering, blue damage, zero damage, prevention, aggregate player/permanent recipients, and the actual death-to-Temple-to-front-face sequence. Additional gameplay cases verify source color/controller/departure snapshots, previous-turn and insufficient-damage activation refusals before payment, combat exclusions, saved replacement-order prompts, and current-controller source filters.
