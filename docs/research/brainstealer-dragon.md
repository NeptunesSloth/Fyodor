# Brainstealer Dragon

The end-step ability compiles to native exile_top for each opponent, binding the exact new exile objects, followed by persistent native play/cast permissions. The permissions survive the Dragon leaving or changing control; each remains with the original ability controller. Their color flexibility applies only when casting through that permission. It neither makes spells free nor turns colored mana into colorless mana for a required {C} symbol. Land plays retain ordinary timing and limits and cause no nonland entry trigger. A card that leaves exile and returns as a new object loses the original permission.

The entry qualifier keeps ownership separate from control. It parses the existing owner-qualified permanent selector, then adds the stated entry controller without overwriting the owner. The owner_antecedent marker is restricted to the unambiguous “an opponent owns … under your control” pattern; broader or ambiguous owner/controller pronouns are not inferred. trigger_words rewrites that marker's leading “they” into “its owner”, using native ref:event.owner and event mana value. This preserves the correct opponent, including when the entrant leaves before resolution.

Canonical gameplay exercises actual paid Dragon casting and end-step exile from multiple opponents; wrong-colored mana paying the ordinary cost; a required {C} refusing colored mana; land limits; exact exile incarnations; source exile and control changes; independent Reanimate effects; the opponent-owned Dragon triggering on its own entry; and empty opponent libraries. The modal-face case uses canonical FULL Birgi // Harnfel, casting Harnfel with five blue mana and charging its owner five life, rather than the front face's mana value three. This avoids relying on unrelated unsupported Tibalt resolution.

Fixtures copy complete metadata and all modal faces for fifteen actual Oracle cards. Persistent permissions and choices check replay and JSON save/load. Shared changes are one native-effect parser leaf/hook, the bounded owner-plus-controller event grammar, and explicit owner-pronoun rewriting; the payment, permission storage, and owner/LKI lookup engines are reused.
