# Controller acquisition and continuous control during a turn

Mad Dog, Erg Raiders, and Keldon Twilight are production verified: 19 whole-card checks, including three fresh-process restores, plus 54 phasing/control/combat/automation regressions. Four owned source/kernel files pass mypy; owned source/tests pass Ruff. Canonical texts and all available official rulings were read, including Erg Raiders' entry-or-control-gain ruling. Evidence: `/tmp/counter69-history-production-manifest.json`.

Existing committed control-change events now contribute an exact player/object receipt to the native turn log. Together with native entry receipts this answers whether the original source object came under the ability controller's control this turn, including when it changes controller or leaves before resolution. Mad Dog applies the exception to both intervening-if checks; Erg Raiders retains its original intervening-if and applies its exception only at resolution. Neither a later incarnation nor another player's acquisition supplies the original source's history.

Keldon Twilight retains the native event player and sacrifice choice but filters for continuous control since the turn began. Native known-age control marks supply the actual acquisition turn. Unknown-age marks record only the first turn actually observed: they fail the current-turn test and qualify after a later observed turn begins. Legacy missing observation fields backfill only on a real sync. Phased-out permanents retain their control marks because phasing preserves the object and its control relationship.

Proofs include a genuinely manual new game enabled midway, first-turn refusal then later eligibility, legacy missing observation data, actual paid Slip Out the Back phasing with unchanged marks, control lost and regained, attacks, source leaving/reentering while its original trigger is pending, and separate cold restores for all three cards. The only candidates sharing these exact canonical wordings were these three cards.
