# Unblocked combat riders

Delif's Cone, Delif's Cube, Gaze of Pain, Farrel's Mantle and Rysorian Badger share the native unblocked event (CR 509.3g). This event happens after blockers are declared, including an attacker put onto the battlefield attacking; it is distinct from declaring an attack. The official Rysorian Badger ruling of 2013-04-15 confirms this distinction.

The bounded parser leaf `unblocked_riders.py` uses native temporary watches and triggered abilities. Watch validators now permit unblocked events about one bound object or matching creatures; other refused event shapes remain refused. Each deferred trigger captures the exact attacker and defending player through the existing TriggerEvent. Gaze chooses its damage target when each delayed trigger is put on the stack, rather than when the sorcery resolves. Delif's artifacts watch the exact original targeted creature. The source artifact and the watched attacker remain separate references: Cube counters go on the artifact, while combat assignment suppression applies to the attacker.

Suppression uses existing `restrict`/`assign_none`, which changes combat-damage assignment (CR 510.1a), rather than preventing damage. Native damage, life-gain and exile replacement pipelines remain in use. Optional choices reuse serialized native `may_rest` continuations, with optional chooser and life-gain-cost constraints. Cone cannot choose to pay a prohibited life-gain action (CR 118.12, 119.7); a replacement that turns the gain into loss still pays that action (CR 118.11). A zero-power life gain remains a zero action unless prohibited.

Farrel's Aura controller controls the triggered ability and chooses its target. The creature's current controller chooses whether it deals damage when the ability resolves, using the exact event creature's current or last-known controller. Damage comes from that creature, equal to its current or last-known power plus two. Another target excludes the event creature, rather than the Aura. The shared native event-object target exclusion now accepts unblocked events. Control changes in response are tested using actual Act of Aggression.

Badger's target group binds the frozen defending player's graveyard before choosing up to two creature cards. Unbound defending-player ownership fails closed. Accepting the optional zero-target action succeeds and suppresses combat assignment while gaining zero life (CR 118.12); actual cards exiled this way determine the life gained. An ability with a nonempty original target group whose targets all become illegal does not resolve (CR 608.2b).

Canonical fixtures retain actual Oracle metadata. Gameplay tests exercise source loss, exact creature identity, optional decline/accept, current host controller, target timing, zero/one/two-card exile, partial or wholly illegal targets, prohibited and replaced life gain, save/replay and cold restored native choices. Broader unblocked abilities are not implemented merely by accepting their event wording.
