# Nighthowler and Eidolon of Countless Battles

Their joint subject describes independent continuous effects on the source and on its enchanted creature. The implementation expands the subject through the existing `static_pairs` sibling mechanism; the existing layer table gives every sibling the same source, controller, and timestamp. No card-name script or layer engine change is needed.

Nighthowler produces two ordinary static grants: the source and its host each get +X/+X, where X counts creature cards in all graveyards. Eidolon produces four grants: source/host each get the creature-count bonus and the Aura-count bonus separately. These quantities are additive, not a union of matching permanents. The current controller of the source defines "you," including when it enchants another player's creature.

The [Nighthowler official rulings](https://api.scryfall.com/cards/b76dab3d-1788-4ab7-8d2b-70f7787cf935/rulings) state its last ability functions only on the battlefield and that in other zones it is a 0/0 enchantment creature. The [Eidolon official rulings](https://api.scryfall.com/cards/4ad6fcb1-7c35-4111-8f1e-d18a2fae5638/rulings) give the same battlefield-only rule and explain that a bestowed permanent is normally either a creature or an Aura, contributing just one to Eidolon's combined count. Both cards' rulings describe the bestow exceptions when the target is illegal or the Aura becomes unattached: the source becomes an enchantment creature rather than being countered or put in the graveyard.

An Aura creature is a possible transient state during resolution, but CR 303.4d prevents an Aura creature from enchanting anything, and state-based actions will remove the illegal attachment/Aura afterward (704.5m). The additive-count test therefore uses a read-only `Plan` to derive an animated Rancor in the legitimate interval before state-based actions, verifies it contributes once as a creature and once as an Aura, and verifies the original game is untouched. It does not assert an illegal Aura creature survives a completed game action.

Verification: 14 focused cases cover actual normal and bestow casts, host death and unbestowing, the bestow target becoming illegal before resolution, battlefield-only pump behavior, direct phasing out/in of the Aura, Humility removing all sibling effects from a creature source, controller versus owner/host controller, and the transient double-count case. Every gameplay case checks replay and JSON save/load. Four existing bestow-related regressions and 72 static/conditional-static regressions pass. The ten-card fixture contains complete canonical metadata from the Oracle database. Relevant CR: 604.1–2, 611.3, 613.4c, 702.103, 303.4d, 704.5m.
