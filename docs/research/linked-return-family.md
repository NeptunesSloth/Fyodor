# Exact linked retrieval and movement outcomes

Canonical eleven: Ethereal Forager; Nyla, Shirshu Sleuth; Underworld Sentinel; Wall of Mourning; Purgatory; Bag of Devouring; Endless Horizons; Bottled Cloister; Asmodeus the Archfiend; Ghost Vacuum; Pinnacle Starcage.

Linked retrieval reads original exile ObjectRefs under the source incarnation and borrowed ability scope (607.2a/607.2q). Nontargeted choices are made as the ability resolves; targeted returns announce an exact linked target and retain normal legality checks. Owner restrictions filter the pool, while owner-hand destinations remain distinct from battlefield control. Under CR110.2a an omitted battlefield controller defaults to the instructed player; explicit owner-control wording continues to mean owners. A source's current controller can therefore return another player's owned card under their own control where the Oracle omits an owner-control clause.

Printed delve has native CostContribution records rather than PaymentRecord.exiled entries. A backward-compatible exiled_object_id snapshot now records the actual new exile incarnation immediately after paying delve. The resolved permanent links only those exact still-exiled objects, and only for its actual printed delve ability. The old graveyard object cannot identify a card that left exile and returned. Legacy records missing the new snapshot do not guess. Native tests also cast a Clone using Underworld Breach and copy Forager on entry: those foreign escape payments do not become linked delve cards.

Asmodeus's understood draw-replacement body records its own native exile instructions under the replacement source. Its return's life loss uses the native this_way returned outcome: hand moves intentionally preserve only historical references, so counting current public object references would incorrectly return zero. Pinnacle similarly counts actual graveyard arrivals, giving zero Robots when Rest in Peace replaces the moves. Neither operation fabricates an event_amount or counts the original pool blindly.

Ghost Vacuum uses native return/entry choices and a flying counter, then the existing permanent base-power/toughness and additional creature-type effect over the actual returned refs. A fresh-process Clone entry-choice regression verifies that the continuation retains its flying counter, 1/1 base, added Spirit type, and original ownership. Bag uses the native recorded d10 result and native up-to return choice, including a fresh-process pending decision. Wall and Bottled Cloister exile face down blindly; their original owners do not receive an implicit right to inspect their exiled cards.

Canonical gameplay tests cover each card's native exiling and retrieval path, payment/optional choices, source sacrifice/death and control changes, private views, actual die result, stale exile incarnations, default versus explicit battlefield control, replacement outcomes, and save/replay/cold entry choices. Neighboring linked-return, linked-exile, movement-outcome, cost-helper, cost-contribution, and entry-value suites pass.
