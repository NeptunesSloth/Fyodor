# Jade Orb of Dragonkind and Study Hall

Both cards use canonical Oracle metadata, alongside five already automated spent-mana references (Scaled Nurturer, Gilanra, Lapis Orb, Path of Ancestry and Pyromancer's Goggles). The new behavior reuses source-tagged mana units, normal delayed triggered abilities, native counter-entry replacements, and layer-six keyword effects.

Jade Orb's extra counter and hexproof are attached to the exact Dragon spell only when its spent-mana trigger resolves. Stifle can counter that trigger; Counterspell can still counter the Dragon, including after the trigger resolves. The Dragon spell itself does not gain hexproof. The counter is part of entry, so Doubling Season and Solemnity apply normally. A spell copy does not inherit mana-spent riders, and blink creates a new permanent without the old incarnation's grants.

The keyword rider captures the original caster's turn and turns-taken count. Permanent entry adds hexproof only while that original clock is still live, then native next-turn expiry uses the same caster and original creation turn. Entry cannot restart an expired duration. Other players' extra turns do not expire it; the caster's next actual turn does. A subsequent change of the permanent's controller changes whose opponents hexproof protects against, without changing its expiry. A boundary test loads an actual stored rider with an expired clock and resolves its entry; it explicitly does not claim that a normal legal stack persists across turn boundaries.

Study Hall reads the specific event commander's commander_key and its owner's recorded command-zone cast count. It includes the current command-zone cast, keeps partner counts separate, and does not increment the count for a hand cast or a copied triggered ability. Source departure does not remove the trigger or change its event reference. Its mana ability's activation input is paid independently; spending Jade mana on that input does not transfer the Jade rider to the commander's spell payment.

The shared spent-mana trigger now correctly identifies the mana producer's physical card and original object as its source. It uses the native delayed-trigger index so effects that multiply triggered abilities of permanents (such as Delney) do not multiply this delayed ability. This also preserves the original source after departure or control changes. Each qualifying actual mana unit creates its own trigger; spending mana as though it were another color preserves its original traits.

Gameplay tests use real casts, actual mana payments, counterspells, counter replacements, extra turns, Insurrection, Cloudshift, Double Major, partner commanders and Strionic Resonator. Persisted decisions use actual JSON reload/resume plus history replay. Related native mana, provenance, cast-rider, duration and commander regressions run separately.
