The Fourth Doctor prototype proposes a `create_food69` permission-use receipt. That receipt is not supported by the live typed receipt model or receipt handler. Generic static grants would also need to carry the native receipt. These changes remain unimplemented.

The Belligerent has no implementation in the prototype. Its temporary top-card look/play permission needs an authority that survives source departure, expires at end of turn, and preserves private information. The existing source-bound top reveal is insufficient for that design.

Isu's prototype combines native snow-filtered top permissions and three optional payment alternatives. Into the Pit's prototype uses the native sacrifice-a-nonland-permanent additional cost. Neither prototype has passed native runtime verification.

Required future proofs include top-card privacy, original selected spell identity through milling/shuffling additional costs, and permission-source sacrifice after a legal cast announcement. The saved tests intended to probe Into the Pit source sacrifice, Progenitus replacement shuffling, and Millikin milling during payment; their setup failures establish no counterexample and no confirmed kernel defect.
