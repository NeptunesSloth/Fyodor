# Scholar of New Horizons

The enters-with-counter replacement and activated tap/remove-a-counter cost already use native rules. The remaining search wording adds an optional destination for a single revealed search result: if the native opponent-land comparison holds, its controller may put the card onto the battlefield tapped; otherwise it goes into hand. The search finds any Plains card, including nonbasic Plains, rather than only a basic Plains.

The generic leaf parser delegates search selection and condition parsing to the existing grammars. It adds serializable `optional_to_if` metadata to a normal search effect. The native search finisher first applies Opposition Agent's forced-exile override and reveals the actual chosen card when appropriate. Only then does the leaf ask about the optional destination, with the found card still in its library. The answer consumes the metadata and resumes the native finisher without revealing twice. Direct native entry preserves the card's library origin and all normal entry handling, followed by the original shuffle; the card never passes through hand on its way to the battlefield.

A false comparison, a failed search, an Agent-exiled result, or an impossible optional entry does not prompt for a battlefield destination. An opponent must individually control more lands; opponents' totals are not combined. The comparison is evaluated during resolution, not locked when the activation is announced. Search restrictions, hidden choices, public reveal, control of another player's search, and fail-to-find behavior remain native. Costs have already been paid and are not repeated on destination continuation.

Canonical gameplay/save/replay tests cover the actual enters-with counter; tapping and removing its own counter or another controlled permanent's charge counter; insufficient cost rollback; basic and nonbasic Plains filtering; equal/fewer/greater opponent land counts; accept/decline; source departure and land-count changes before resolution; fail-to-find and shuffle; Stranglehold prohibition; Opposition Agent override; Aven Mindcensor restriction and reveal privacy; and Hallowed Fountain entering tapped without an unnecessary life-payment choice.

Validation: 15 canonical cases and 22 native search-entry, Claim Jumper, and search-control regressions passed (37 unique tests); Ruff passed. Logs: `/tmp/fyodor-scholar-final.log`, `/tmp/fyodor-scholar-regressions-final.log`.
