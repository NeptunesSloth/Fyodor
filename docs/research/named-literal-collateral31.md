# Named literal collateral validation

Rohgahh of Kher Keep and Wirefly Hive use actual Oracle data, including colors, mana value, keywords and type metadata, in `backend/tests/fixtures/named_literal_collateral31_cards.json`.

Rohgahh's current-controller named-creature pump works through the native selector. Gameplay validation exposed an instruction separator being consumed into the literal name in its upkeep ability: `Kobolds of Kher Keep, then an opponent gains control of them` had been treated as one name, silently omitting control transfer. Literal-name selectors now reject the instruction separator `, then ` while retaining comma-bearing names. A narrow grammatical form handles the tap-and-transfer sequence using existing effects: tap the union of the source and all creatures with the stated name, record the complete original group with `as`, then give that exact bound group to one opponent chosen on resolution. The native tap binding records already-tapped objects too. Native control effects, opponent decisions and saved continuation handle resolution; no new callback or control engine was introduced.

Canonical tests cover both sides of the optional red payment, all controllers' named creatures, exclusion of another Kobold name, current-controller pump changes, already-tapped recipients, replay and a fresh-process restored opponent decision. Wirefly Hive tests use recorded native coin flips: a win produces a 2/2 colorless flying Insect artifact creature named Wirefly; another win produces another; a loss destroys Wireflies controlled by another player while preserving other-named creatures and the Hive. Save/replay retains outcomes.
