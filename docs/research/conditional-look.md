# Conditional inspected-card replacements

Canonical family: Flow State, Accumulate Wisdom, See the Truth, Gather the Pack and Rowan's Grim Search. All fields in the fixtures come from the actual Oracle database. The implementation compiles their instructions into existing native look_top, pick_looked, rest_looked, only_if and kicked_gate effects; it adds no payment or copy evaluator.

A conditional replacement chooses one branch as the instruction is reached, with the existing only_if bind/flag mechanism. Its verdict persists across choices and JSON reload. The alternative branch reads that flag instead of judging the changed graveyard after selected or remaining cards move (CR608.2c). Gather's separate Spell Mastery text merges through the existing _merge_instead_lines pipeline.

Flow State requires an instant card AND a sorcery card in the controller's graveyard. A single card with both types can satisfy both requirements. Gather instead counts cards matching instant OR sorcery, so that same split card counts only once toward two cards. Native selectors distinguish conjunction of existence tests from a union count. The resolving spell remains on the stack, so it does not count toward either graveyard test. Accumulate Wisdom similarly needs three Lesson cards already in the controller's graveyard.

See the Truth reads the original spell's native cast-from record. Actual granted flashback through Past in Flames produces the upgraded three-card result. A Reverberate copy of that spell was never cast and retains the normal one-card result; the original subsequently takes three. This is explicitly stated by the WotC ruling dated 2020-06-23.

Rowan keeps the existing bargain payment pipeline. Its conditional block uses native kicked_gate, which reads the copied additional-cost decision. A copy of a bargained spell remains bargained, as explicitly stated by WotC2023-09-01; it does not pay the sacrifice cost again. Both bargained and unbargained versions always continue with the ordinary two draws and two life lost. The chosen kept cards use a new top_any counterpart to the existing bottom_any destination in native _picked: multiple kept cards ask the original controller through the existing private order_library continuation. It retains exact inspected object IDs and the untouched cards remain available for the next native rest instruction.

Gameplay validates both branches and thresholds, a real Crypt response removing the graveyard before resolution, the split-card distinction, actual flashback and copied spells, real bargain paid/declined and copied, short/empty libraries, no creature options, native Rest in Peace moves and Spirit of the Labyrinth draw prohibition. Pending choices cold-restore JSON and replay history. REST/WebSocket tests inspect opponent and spectator frames through private picking, private ordering and completed hidden destinations.

Official WotC ruling evidence was fetched through Scryfall for See the Truth, Gather the Pack and Rowan's Grim Search. Gather's 2015-06-22 ruling confirms mastery is checked during resolution and the resolving spell does not count. Flow State and Accumulate Wisdom had no additional WotC rulings in the fetched data. The local Comprehensive Rules snapshot is dated 2026-09-25.
