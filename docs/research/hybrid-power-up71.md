The existing power-up implementation already handles entry-turn discounts and once-per-object limits; these three cards were blocked by ordinary hybrid symbols. It enumerates both concrete activation halves and reduction halves, then deduplicates the resulting reduced mana costs before other generic modifiers. Snow, Phyrexian, unrelated hybrid structures, and unsupported symbols remain refused.
