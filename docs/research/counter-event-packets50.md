# Committed counter event packets

Bold Plagiarist and Captain Marvel, Apex Avenger need the counters actually put by one triggering instruction, rather than the recipient's counter total when the trigger resolves. The staged kernel captures each committed positive placement with its exact object, kind and amount. Native all-kind instruction joins preserve these entries and update native multiplied triggers. CounterPlacement moves into the data-only rules state module and is re-exported at its original import path; the new event list defaults empty for existing saves.

The exact two printed triggers delegate their ordinary event conditions, Captain Marvel's Kree intervening condition and optional choice to existing native grammar. A dedicated primitive reads the retained packet, then delegates the complete multi-kind instruction to native add_counters. Bold Plagiarist uses the frozen actual event actor as putter. Generic script guards are unchanged. A legacy save without a recorded packet never infers counts from its current board.

Twenty-three isolated native tests pass (21 in /tmp/counter50-packet-whole-final-staged.log, two keyword cases in /tmp/counter50-packet-keywords-staged.log), including two genuine fresh-process reloads. They cover paid source casting, actual three-kind Gift of the Viper, actor-sensitive Vorinclex, independent counter replacements, forbidden counter placement, wrong actor/recipient, optional decline, Kree exclusion and actual Wings of Velis Vel changing the event creature before resolution, removing triggering counters before resolution, a blinked source successor, and the opponent's own Plagiarist staying silent. Native keyword witnesses include Bold's opponent-upkeep flash cast and Captain Marvel surviving actual Murder, rejecting a ground blocker and dealing eight double-strike damage. All available official rulings were read. A further 162 related counter/trigger checks pass; scoped mypy on four sources and owned Ruff pass.
