# Exact linked-pool aggregates

The linked set is keyed by the source's object incarnation and, for borrowed abilities, its independently saved borrowing scope. Queries retain only the exact exile incarnations recorded by that source (CR 400.7, 607.2a). Leaving exile and later exiling the same physical card never restores the old membership. Triggered contexts keep their original source object even after it leaves; live statics explicitly construct a current-source context.

The shared projections count cards, count creature cards, count distinct mana values, form a union of current card types, or read the latest linked creature's current power, toughness, and creature types. Face-down exile contributes no hidden printed types or printed mana cost. Duplicant's admitted exiling instruction exiles one target at a time; the implementation does not invent simultaneous-last ordering for generic multi-card exilers. Its continuous effect begins in layer four and continues into layer seven (CR 613.6), retaining Shapeshifter without copying abilities or colors.

Consumers cover Negative Zone Portal, Colfenor's Urn, Profane Procession, Azor's Gateway, Lumbering Battlement, The Kenriths' Royal Funeral, Cemetery Prowler, Cemetery Illuminator, Duplicant, Redemptor Dreadnought, Hostile Hostel, and River Song's Diary. Their additional instructions use native target groups, ordinary nontarget choices, exact linked exile, transformation, optional costs, sacrifice, entry, and cast-now continuations. The Funeral snapshots the greatest mana value of the actual newly exiled objects in a normal amount binding before draw replacements can pause the resolution. Cemetery Prowler counts distinct shared types; Illuminator tests the actual resulting spell's types with normal timing, mana payment, and once-per-turn consumption.

Transformation preserves the source incarnation. Only true transforming face metadata validates a linked ability whose exiling half is printed on the opposite face; it does not grant that face's abilities. Colfenor's Urn's sacrifice is mandatory and a missing or unsacrificable source cannot pay it. Negative Zone Portal's return follows its sacrifice without an "if you do" gate. Lumbering Battlement uses the native exile-until-leaves choice and does nothing if its source has already departed (CR 610.3b).

Canonical fixtures retain colors, mana values, keywords, full faces, and printed power/toughness. Gameplay tests create every pool through the actual printed instruction. They verify real entry/attack/activation effects for all twelve, source departure, owner-versus-controller retrieval, current dynamic creature characteristics, exact exile-incarnation filtering, and JSON round trips. Separate fresh-process tests resume Profane's linked retrieval, Gateway's fifth hand exile, and both acceptance and refusal of Diary's random free cast without importing test callbacks.
