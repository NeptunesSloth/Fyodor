# Conditional destinations for revealed searches

Loyal Inventor, Guidelight Pathmaker, From Father to Son, Stoic Farmer, Embermouth Sentinel, and Nazahn reuse ordinary library searches. The native search owns hidden choices, reveal, optional-search refusal, Mindcensor depth, Opposition Agent control and exile permissions, battlefield entry, and shuffling. Card-dependent branches use the existing to_if selector; source/table conditions are read when the found card is assigned and cannot override Agent's exile destination.

Loyal Inventor puts the card into hand only while its controller controls an Assassin; otherwise the revealed card is tracked through the shuffle and put on top. Embermouth Sentinel puts a found basic land onto the battlefield tapped while its controller controls a Dragon; otherwise it uses the same shuffle-and-top path. Declining these optional searches never shuffles. Stoic Farmer's basic Plains enters tapped only if an opponent controls more lands; Guidelight's artifact enters only at mana value 2 or less, otherwise it goes to hand. Nazahn puts only a card named Hammer of Nazahn onto the battlefield and puts other Equipment into hand.

From Father to Son tests the exact source spell's actual cast origin. Printed flashback provides a real graveyard cast. An actual spell copy was not cast from a graveyard, even when the original was, so the copy's found Vehicle goes into hand. This uses ordinary cast-history predicates and deliberately differs from copied alternative-cost decisions such as Verdant Mastery.

Rootpath Purifier's single missing static is parsed into the existing layered Basic supertype addition: controlled lands on the battlefield and owned land cards in the library. It does not affect hand, graveyard, or opponents' libraries. It changes neither land subtypes nor printed abilities. Native copied statics, control changes, and source departure update its scope.

Rootpath supplies a real entry-prohibition regression: Dryad Arbor becomes a basic land card in the library, Embermouth can find it, and Grafdigger's Cage prohibits its battlefield entry. Its assigned destination remains battlefield despite that failure. The library is shuffled once and the card must not be put on top as a fallback. The native top-placement loop now follows the actual per-card top destination, rather than the search's default destination.

Fixed card names are not references to the ability's source (CR 201.5). Both self-name normalization and renamed-copy text preserve complete card/token named literals, including Hammer of Nazahn when Nazahn is copied as Sakashima the Impostor. Genuine source references still follow the new name. Existing consumers now accept these fixed literals: counted mana uses native fixed-name selector counts; grandeur preserves an entire named-card discard cost before splitting commas; deck and draft declarations preserve their prior supported status. Actual Sakashima copying Korlash discards the explicitly named Korlash card and tutors normally.

Canonical gameplay covers ordinary and flashback casts and actual copies, Hammer's real attach trigger, renamed copies, optional decline and finding zero, source/controller scope, actual prohibited entry, Agent diversion, and hidden search/hand versus public battlefield results over HTTP and WebSocket. Each decision is saved and replayed through native continuations. Existing copied-name, mana-rider, search-control, partition, and grandeur regressions are included.
