# Cross-target qualities for permanent exchanges

Actual Oracle text and official rulings were fetched before implementation for [Puca's Mischief](https://scryfall.com/search?q=%21%22Puca%27s+Mischief%22), [Daring Thief](https://scryfall.com/search?q=%21%22Daring+Thief%22), [Legerdemain](https://scryfall.com/search?q=%21%22Legerdemain%22), [Spawnbroker](https://scryfall.com/search?q=%21%22Spawnbroker%22), [Conjured Currency](https://scryfall.com/search?q=%21%22Conjured+Currency%22), and [Djinn of Infinite Deceits](https://scryfall.com/search?q=%21%22Djinn+of+Infinite+Deceits%22). The fixture retains full canonical characteristics and rules text.

`permanent_exchanges` parses native exchange instructions and adds typed `relative_quality` metadata to dependent target groups. Existing `of` references identify the earlier target group. The normal player-relative binder delegates this metadata to an immutable selector binding at each validation, resolution and retarget query. It never persists an announcement-time mana value, power or type as a replacement for the original target reference.

Puca compares current mana values; Spawnbroker compares current signed power. Mana-value thresholds retain their numeric value rather than rounding the Characteristics float representation. Daring Thief compares all current card types, including Kindred; Legerdemain restricts the shared type to Artifact or Creature. Sharing an unrelated type or creature subtype is insufficient. Unknown earlier-object facts match no candidate, while an exact departed object uses the engine's last-known snapshot. A real Flicker of Fate regression distinguishes an old boosted5-power object from its returned2-power incarnation.

The bounded two-singleton dependency prunes first choices without any legal completion. This implements Puca's explicit ruling: players must select a legal target set even if they intend to decline the exchange. Candidate facts are derived once per pruning pass, with public battlefield information only. Existing unrelated target graphs remain unchanged.

The native exchange effect remains authoritative: both objects must still be legal battlefield objects and controlled by different players; otherwise neither changes controller (CR701.12). Creating both layer2 effects precedes one control synchronization. Control changes preserve object identity. Optional exchange choices occur after targets are selected. Native copying and retargeting rebind the second group's restriction to the newly chosen first target, and reject an incompatible final pair even if one target was kept.

Conjured Currency's target must be both owned and controlled by someone other than its original ability controller; those other players may differ. The actual source's current controller participates in the exchange, while target restrictions still refer to the original ability controller. A returned source is a new object and cannot participate in an old pending exchange. Djinn's exact negative combat sentence uses the native activation-restriction condition; tap, haste and summoning-sickness checks remain intact.

Canonical tests exercise actual spell, entry, upkeep, untap and activated-ability flows; optional acceptance/decline; no legal pair; Kindred-only and artifact-land relations; negative power; changed power/type at resolution; source theft/departure/blink; exact native LKI; one versus all illegal targets; same-controller no-op; copied retargeting; replay and JSON serialization. Fresh-process tests resume each of mana-value, power and shared-type second-target choices, including private view projection before the first action.

Modify Memory was researched alongside this family but remains outside the scope: its separate conditional draw rider needs its own exact interpretation and runtime proof.
