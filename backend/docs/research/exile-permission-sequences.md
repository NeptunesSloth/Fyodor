# Exact exiled-card permission sequences

Fourteen canonical cards share native composition of actual exile results, selection, normal casting, costs, scoped filters and durations: Soul Partition; Suspend Aggression; Author of Shadows; Chandra, Flameshaper; Vivien, Champion of the Wilds; Nahiri, Forged in Fury; Riveteers Charm; Shadow Urchin; Tavern Brawler; Redcap Gutter-Dweller; Synth Eradicator; Ardent Dustspeaker; Court of Locthwain; Rashmi and Ragavan.

The new leaf builds standard typed effects with explicit `as` and `ref:` bindings. Existing permission/casting machinery retains exact rules-object identity, alternative/additional costs, timing and land limits. No casting CPS changes are introduced. The existing actual-exile chooser gains an optional native selector filter; owner grants can add a generic increase only for the granting player's opponents.

Soul Partition grants the owner normal play with a permission-specific opponent-only tax. Suspend Aggression grants each owner a separate next-turn clock. Author selects only nonland actual exiles. Chandra chooses one of three actual results after adding mana. Vivien must choose even a noncreature; a face-down card remains private and known to its exiler, while only a creature spell qualifies for the permanent cast permission. Nahiri grants normal paid play and a separate free Equipment-spell option, both retaining normal timing. Riveteers' first mode uses an opponent's native untargeted choice among maximum-MV creatures/planeswalkers, while its other modes use existing native timed permissions/zone sets.

Shadow Urchin's 'that many' is bound only by a singular counter-qualified death trigger, never guessed from an unrelated bare body. It reads all counters from the dead object's event/LKI, including counters which are removed in the same simultaneous SBA check. Tavern Brawler freezes the exiled card's mana value before pumping its commander source. Redcap's native optional sacrifice payment gates all rewards. Synth records accepted versus declined energy independently from the amount actually received; mandatory replacements can reduce accepted energy to zero without granting play. Ardent uses an optional exact graveyard-card bottom choice and normal native movement before the gated exile/play sequence.

Court links exact objects to the Court incarnation. Paid grants persist independently; monarch resolution grants one shared free-use group over old and new linked exiles. Rashmi creates Treasure before freezing its strict free-cast threshold, uses native immediate casting, and grants paid casting only if not cast. Its printed first-spell/own-turn trigger eligibility stays native.

Canonical fixtures retain complete metadata. Actual casts, activated/triggered effects, legal and illegal targets, normal/paid/free casting, private face-down choices, source departure, shared group consumption, strict thresholds, simultaneous opposing counters, energy replacements, native mode choices and fresh-process resumes are verified. Exile obfuscation can renumber card IDs, so cold tests follow the exact permission's current card instead of assuming a hidden old ID survives.

Abstruse Appropriation is deliberately still PARTIAL. Its permission allows only colorless mana to substitute for colors; existing unrestricted any-color spending would be broader than Oracle. It requires a separate sound source-specific payment matcher extension.
