# Dynamic and timed hand limits

Canonical Oracle text and official rulings were fetched before implementation for [Midnight Oil](https://scryfall.com/search?q=%21%22Midnight+Oil%22), [Winter, Misanthropic Guide](https://scryfall.com/search?q=%21%22Winter%2C+Misanthropic+Guide%22), [Inspired Idea](https://scryfall.com/search?q=%21%22Inspired+Idea%22), [Enter the Infinite](https://scryfall.com/search?q=%21%22Enter+the+Infinite%22), and [Mordenkainen](https://scryfall.com/search?q=%21%22Mordenkainen%22). The canonical fixture preserves their complete Oracle text, costs, colors, mana values, loyalty and other characteristics.

The hand-limit evaluator reads dynamic static SET values from the existing typed value evaluator. Conditions such as delirium are checked against the current source controller and table. A changing value or a condition becoming true does not give the source a new timestamp. Winter's official ruling specifically distinguishes when the source entered from when delirium became true.

Resolving player-rule modifiers use an optional typed `ContinuousEffect.hand_limit` payload. They affect no permanent characteristics: the record supplies the native timestamp, source provenance and existing duration expiration. Permanent reductions accumulate; an unlimited maximum ignores reductions while applicable. Fixed SET, unlimited and delta effects retain timestamp order. A temporary unlimited effect ending reveals older reductions again. Existing rest-of-game no-maximum and legacy-save handling remains intact; old continuous-effect saves default to no hand-limit payload.

Inspired Idea's cleaved spell omits the bracketed rider through the ordinary casting pipeline. Enter the Infinite determines library size when its draw instruction resolves, uses native draw replacements, privately puts one card back, and grants unlimited hand size until its controller's next turn begins. The standard expiration engine also handles skipped/departed-player turns. Large consecutive draws are committed through table Draw actions of at most 100 cards without introducing priority or state-based checks between chunks; the original instruction and its per-card draw events remain intact.

Mordenkainen's +2 extends the existing private put-back primitive with a saved placement field, defaulting to top for old saves. Its ultimate exchanges complete hand/library sets with one mixed-destination Move, then uses native shuffle and emblem generation. This is neither drawing nor discarding, including when either set is empty (CR701.12d/f). The source can leave after paying loyalty without affecting its pending ability.

Each commander replacement is chosen and prepared before either zone changes. The continuation records exact object IDs and original zones, and commits all prepared routes together. It does not rely on the general commander preflight, which excludes commanders already in hand/library. Only the acting player receives private card choices; continuation frames and hidden identities are not projected to other players. Native hidden-card renumbering on shuffle remains authoritative.

Canonical gameplay tests cover counter-defined and delirium-defined limits, original timestamps, multitype graveyards, normal/cleaved casts, repeated permanent reductions, no-maximum expiration, actual Midnight Oil cleanup discard/life-loss triggers and repeated cleanup, draw restrictions and draws above 100 cards, private bottom placement, zero/unequal zone exchanges, native Dog token CDA, all four commander replacement outcomes, replay/JSON roundtrips, and fresh-process exchange/put-back resumes.

The catalog audit also promoted [Amass the Components](https://scryfall.com/search?q=%21%22Amass+the+Components%22) and [Errand-Rider of Gondor](https://scryfall.com/search?q=%21%22Errand-Rider+of+Gondor%22) through the same bottom-placement grammar. Independent canonical tests verify each native draw/put-back instruction, Errand-Rider's own versus opposing legendary-creature condition, private projection, replay, and both fresh-process resumes. These cold tests also exercise projecting a saved game before its first action: the view loads Licid helpers lazily rather than forming a module-initialization cycle through payment continuations and the parser registry.
