# Chosen-player event, recipient, attack and hand-size bindings

Canonical Oracle text and official rulings were fetched before implementation for [Sewer Nemesis](https://scryfall.com/card/clb/771/sewer-nemesis), [Sawhorn Nemesis](https://scryfall.com/card/m3c/60/sawhorn-nemesis), [Triarch Stalker](https://scryfall.com/card/40k/67/triarch-stalker), [Beckoning Will-o'-Wisp](https://scryfall.com/card/clb/10/beckoning-will-o-wisp) and [Cursed Rack](https://scryfall.com/card/me1/155/cursed-rack). The fixture retains the actual card characteristics and complete rules text.

`keyed_player_bindings` connects these independently supported effects to the existing source-object-keyed player choice. The repeatable combat choice stores only its own source's newest player ID. A pending choice cannot bind a returned incarnation; copying a source does not copy its choice. Directly attacking the selected player is distinct from attacking a planeswalker or Battle. The static qualifier applies to attacking creatures regardless of their controller.

Sewer Nemesis compares each actual spell-cast event's player with the source's choice. The existing generic watcher interval supplies the source's old object ID after departure. This matters when flashback of the selected player's last graveyard card makes the Nemesis die before trigger collection. The mill uses the captured event player even after the source leaves.

Sawhorn Nemesis contributes an ordinary native damage-replacement candidate. Its recipient condition matches the selected player or a permanent currently controlled by that player; owner and Battle protector do not substitute for controller. Existing replacement ordering, redirection and damage batching remain authoritative.

Cursed Rack feeds the native cleanup hand limit. Hand limits, including no maximum, apply in timestamp order: a later fixed setting can override an older no-maximum effect; later increases and reductions cannot make an unlimited hand finite. This follows the official rulings on [Reliquary Tower](https://scryfall.com/search?q=%21%22Reliquary+Tower%22), [Null Profusion](https://scryfall.com/search?q=%21%22Null+Profusion%22), [Recycle](https://scryfall.com/search?q=%21%22Recycle%22) and [Praetor's Counsel](https://scryfall.com/search?q=%21%22Praetor%27s+Counsel%22), and CR 402.2/613.10. Resolving a rest-of-game no-maximum effect records its latest timestamp, including repeated resolutions.

Older saves retain the original `no_max_hand` list. New companion fields default empty. A legacy list-only entry has no recoverable historical timestamp: its first native action records only an upper bound. Existing ambiguous fixed limits keep the legacy no-maximum result and cleanup emits an explicit native explanation. A setting introduced after that bound has known later order and applies normally. Read-only queries never manufacture historical order or mutate state.

The canonical gameplay suite covers spell casting and last-graveyard-card flashback, damage to players/creatures/planeswalkers, owner/controller differences, repeated combat choices and departed-source decisions, attacking a planeswalker, independent copied Rack choices, source reentry, actual cleanup discard, permanent and resolved-effect ordering, legacy saves, replay, JSON roundtrips and fresh-process choice/cleanup resumes.
