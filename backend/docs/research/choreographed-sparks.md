# Choreographed Sparks: grants on copied creature spells

Canonical Oracle has two modes and “This spell can't be copied.” Its second mode says: “Copy target creature spell you control. The copy gains haste and ‘At the beginning of the end step, sacrifice this token.’” Official rulings explicitly note that an erroneous “next” was removed from that ability: https://api.scryfall.com/cards/0cda4235-4dce-48fe-a8a5-2a952dedbe25/rulings . This is an ordinary ability gained by the copied spell/token, not a one-shot delayed trigger.

The existing native mode and target system handles choosing either/both modes, copying only one's own appropriate spells, and preserving modes, X, targets, and additional/alternative choices. The new generic copy-gain marker validates keyword/quoted ability text through the existing copy-text grammar, but applies it as a layer-6 continuous effect. It never writes these grants into the copy recipe. Under CR 400.7a the effect continues from the copied permanent spell to the token permanent it becomes; copying that token later does not copy the grants. Native copied-permanent resolution carries the layer-6 affected object identity forward alongside the existing layer-1 recipe.

Twinning Staff's replacement-created additional copy receives the same follow-up grant. Parallel Lives does not double a resolving permanent spell copy: it becomes a token, rather than creating a token (CR 707.10f, also explicit in Sparks's rulings). A copied Hydroid Krasis preserves X/entry counters but does not generate an additional cast trigger.

Canonical gameplay tests cover both modes together, instant/sorcery retargeting, copied modal choices and X, copied creature haste attacking immediately, end-step self-sacrifice with the original unaffected, a Clone copying the token without inheriting grants, Staff and Parallel Lives, current-controller triggers, departure before/after the sacrifice trigger, and ordinary recurring end-step behavior. In particular, Dress Down removes the ability for the first end step and Stifle counters a first trigger; the token survives that end step and triggers at the following one. Actual Reverberate cannot copy Sparks on the stack; actual Mizzix’s Mastery can copy the card from exile, cast it with newly selected modes/targets, and let it fizzle when its target has left. Paused copy/retarget/entry/mode decisions and final states round-trip save/load and replay.
