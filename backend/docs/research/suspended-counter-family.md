# Suspended counter objects

Ten canonical cards share physical suspended-card selection and the native counter pipeline: Deep-Sea Kraken, Pardic Dragon, Greater Gargadon, Amy Pond, Clockspinning, Jhoira's Timebug, Rift Elemental, Venser's Diffusion, Dust of Moments and Nihilith.

A card is suspended only while it is face up in exile, has suspend, and has a time counter (CR 702.62b). The native suspend marker records the granted capability; it survives zero counters or declining the last-counter cast, but a genuine departure from exile immediately clears the grant for that object (400.7). Printed suspend is recognized without assuming the suspend special action was taken. Clockspinning and Timebug cannot target an exiled zero-counter card merely because it still has suspend. Tests distinguish this from a manual tabletop counter edit that makes the same object suspended again.

The existing original-source and native counter infrastructure handles casts, counter replacement, actual removals, exile activation and the independent last-counter cast trigger. Gargadon's sacrifice OR list remains a single native cost. Rift's cost admits only controlled permanents or owned suspended cards. Amy chooses during resolution, without targeting, and uses actual combat damage. Pardic's event caster chooses and puts the counter. Nihilith uses individual card entries into opposing graveyards, excluding tokens and moves replaced with exile. Dust captures the instruction's recipients before its native grouped changes. Clockspinning chooses the kind and add/remove action during resolution; spell copies choose independently.

A serializable native frame retains exact recipient object references and answers across counter replacement pauses. Counter additions are planned once using the original descriptor and committed through the native pipeline. No counter input limits or payment stages are widened. The existing free-cast announcement records the exact native suspend-trigger object as provenance for haste; other new grants explicitly record no such provenance. An absent field alone retains legacy saved-announcement behavior.

Tests cover actual positive gameplay for all ten, native suspend actions and grants, zero/new-object lifetimes, source and target rechecks, current ownership and controller, permanent-only counter doublers, mandatory and optional choices, buyback, copying and independent kinds, per-card graveyard events, replay and fresh processes at kind/mode/replacement/last-counter decisions. The generic free-cast versus retained suspend-capability contrast is explicitly a low-level native grant test, not invented canonical card text.
