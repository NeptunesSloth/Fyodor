# Compound prevention and native static grants

Woolly Razorback and Armament of Nyx use one complete static replacement definition with the existing `also` list holding their native layer-6 grant definition. Both effects retain the original permanent, controller and timestamp. The layer collector accepts this additional native grant only after exact whole-definition validation. Coverage rejects changed or empty companion branches; existing static grant producers continue through their ordinary collector.

Woolly reads its current ice counters through native static conditions. It prevents outgoing combat damage and has defender while any ice remains. Its real blocking trigger removes one counter before damage, so the last-counter block deals damage normally. Incoming damage and unpreventable damage follow their ordinary native paths. Losing its actual source ability removes both branches; native expiry restores them.

Armament's prevention remains sourced by the Aura, rather than being granted to the enchanted creature. Thus enchanted-creature ability loss does not erase the prevention effect. Current attachment and derived Enchantment type select prevention versus double strike continuously; the latter is an ordinary conditional native static grant. Source departure and control changes retain their normal meaning.

The prerequisite audit found no prior outer static replacement producer with an `also` list: existing top-level siblings come from static grant pairs, attached pumps, and a draw prohibition. Nested `also` fields in draw effects, costs, and entry counters are unrelated. The bounded coverage guard therefore leaves existing producer shapes intact.

The adapter-free production suite passed 28 cases, including two genuine fresh processes loading before combat, same-source/controller/timestamp checks, complete-shape negatives, current type/attachment changes, ability loss/restoration, all printed lines, native blocking and both first-strike and regular damage. Exact new-only names are Woolly Razorback and Armament of Nyx. Central catalog verification is tracked by the batch audit.

Old Fat Spider Can't See Me is registered with an exact second-chapter body and a modern replacement record lasting while its original Saga object remains on the battlefield. Native proofs cover source departure, blink, all-illegal/zero targets, chapter progression and final Saga sacrifice.

The Saga duration uses the existing `source_on_battlefield` name and native original-source check. CR 702.26f explicitly ends a “for as long as” duration tracking a permanent when that tracked permanent phases out. This differs from the target creature phasing: that event preserves its original object ID and does not end the duration tracking the Saga. Modern replacement records therefore use irreversible expiry from the existing `delayed.expire` lifecycle, as well as a pure active check when discovered. A source that phases back in does not reactivate an ended record. Records whose creator departed remain applicable if the tracked source still exists under a live player, as required by CR 800.4m.

Sixteen production Saga cases are verified: fifteen cases in the full run plus the corrected auxiliary Stifle test in a focused run. They cover automatic four-chapter progression, draw and sacrifice; source control, departure, blink and independent native Copy Enchantment sources; departed effect creator; zero/all-illegal targets and source departure before resolution; two fresh processes; actual source-versus-target phasing through Clever Concealment; canonical coverage; and the counterable native chapter trigger. No source or duration adapters remain. Related native timed damage, phasing and joint damage checks passed 48 cases. Central batch 44 catalog verification found exactly the intended promotions and no losses or unexpected changes.
